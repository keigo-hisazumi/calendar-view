# カレンダーアプリ - 予定共有

他人と予定を共有することを想定したカレンダーアプリのモックです。月間カレンダーで予定を追加・編集・削除でき、データはブラウザの localStorage に保存されます。

公開 URL: <https://keigo-hisazumi.github.io/calendar-view/>

## 主な機能

- 月間カレンダー表示（前月・翌月への移動、今日と選択中の日を強調表示）
- 各日に予定のタイトルを最大 2 件表示し、それ以上は件数（`+N`）で表示
- 予定の追加・編集・削除（タイトル・日付・時間・説明）
- 日付を選ぶとその日の予定だけを時間順に一覧表示（未選択時はすべての予定）
- 予定の共有設定（共有ユーザーの選択。共有した予定はカレンダーと一覧で色分けして表示）
- 予定をブラウザの localStorage に保存
- スマートフォン・タブレットに対応したレスポンシブデザイン
- ホーム画面に追加して単独のアプリのように開ける（Web App Manifest とアイコンを同梱）

## 使い方

1. 月間カレンダーで予定を確認する（`<` `>` ボタンで月を移動）
2. カレンダーの日付をクリックして選択する（右側の一覧がその日の予定に絞り込まれる）
3. 「新しい予定」ボタンをクリックして予定を追加する
4. 共有する場合は「他のユーザーと共有」にチェックを入れ、共有ユーザーを選択する（Ctrl / Cmd キーを押しながら複数選択可能）
5. 予定一覧の編集ボタン・削除ボタンから予定を編集または削除する

## モックアプリについて

このバージョンはモックアプリとして作成されており、次の点に注意してください。

- データはブラウザのローカルストレージに保存されます
- ユーザー認証は実装されていません
- 実際の共有機能は実装されていません（UI のみ。共有ユーザーはアプリ内に固定のサンプルユーザーです）
- サーバーとの通信は行われません

## 開発

### 必要な環境

- Node.js 22（CI・デプロイのワークフローと同じバージョン）
- npm

### コマンド

```bash
npm ci             # 依存関係のインストール
npm run dev        # 開発サーバーの起動
npm run lint       # ESLint
npm run build      # dist/ に本番ビルド
npm run preview    # ビルド結果のプレビュー
```

## ディレクトリ構成

```text
src/
  main.jsx          エントリーポイント
  App.jsx           画面全体と予定データの管理（localStorage への保存）
  components/       カレンダー・予定一覧・予定フォームのコンポーネント
  style.css         スタイル
public/             Web App Manifest・アイコン
index.html          HTML のエントリーポイント
vite.config.js      Vite の設定（ベースパスに合わせた manifest の書き換えを含む）
```

## デプロイ

- `main` への PR マージ時に `.github/workflows/deploy.yml` が GitHub Pages（`/calendar-view/`）へデプロイします（Actions の画面から手動実行も可能）
- PR ごとに `.github/workflows/pr-preview.yml` がプレビューを `gh-pages` ブランチの `pr-<番号>/` に公開し、URL と QR コードを PR にコメントします（PR クローズ時に削除）
